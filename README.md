# Dice Simulation Entropy Demo

This repository contains Python code for simulating systems of dice and studying their statistical behavior through energy distributions, entropy, heat capacity, inverse temperature, and equilibrium-like behavior. The project was developed to support numerical experiments for a research paper whose results are produced using this code.

The simulation treats collections of dice as simple statistical systems. Each roll produces a total “energy,” and repeated sampling is used to estimate the frequency of different energy configurations. The resulting data can be used to study statistical-mechanical concepts such as entropy, equilibrium behavior, Boltzmann-like probability distributions, and the qualitative behavior associated with the second law of thermodynamics.

## Research Context

This code was developed as part of a research project on statistical behavior in dice-based model systems. A paper based on the simulations and results generated by this repository is currently being prepared for publication.

## Installation

Clone the repository:

```bash
git clone https://github.com/YungHairStyle/Dice_simulation_Entropy_demo.git
cd Dice_simulation_Entropy_demo
```

## Usage

Run the main simulation script from the root of the repository:

```bash
python src/main.py
```

The main parameters are set inside `src/main.py`.
